# Projet n°1 : Jadoo, restaurant japonais

## contexte

Entrée dans la formation [Onlineformapro de Nevers en développement web et web mobile](https://www.facebook.com/Onlineformapro) le 6 mars je me suis attelée à leur premier challenge : la création d'une page web en HTML/CSS pour le restaurant fictif Jadoo. 
L'école a fourni [la maquette figma](readme/maquette-restaurant_jadoo_Online_formapro.png).
Ma connaissance du code était très basique : quelques cours suivis sur Openclassrooms, 0 compréhension de l'emboitement des boites en CSS, 0 connaissances du flex, 0 connaissance du grid. 

## difficultés identifiées durant le projet

- apprendre a prioriser : la base pour moi, étaient les BOITES. Maîtriser le flex était mon objectif. Partiellement réussi. Abandon des objectifs trop difficiles en les repoussant pour le prochain projet : 
    - [ce template](readme/template_abandonne.png) : les deux petites images en position:absolute, que je ne maîtrisais pas
    - les animations présentes sur le site à imiter
- l'utilisation de px où la mort du responsive : je ne connaissais pas les rem, les vh, les vw, juste les px, et je pensais que comme la maquette était en px... le plus simple serait de suivre à la lettre dans le CSS en appliquant des px. Ensuite j'ai découvert la chaine youtube de [Kewin Powell](https://www.youtube.com/@KevinPowell) et j'ai découvert un peu tard les rem, les em, les vw, les vh, et je me suis dit que je les appliquerai au prochain projet. 
- *je ne sais pas structurer ma page* pour le responsive, j'ai du cacher tellement d'éléments desktop pour les copier-coller légèrement différemment en mobile version. Un ami a passé son temps à me dire "mobile-first" et je ne comprenais pas. Je me suis promis de tenter un jour le mobile-first (un jour), et en attendant j'ai juré de structurer mon prochain projet à la main, au crayon, pour ne pas retomber dans les mêmes erreurs. 
- aucune connaissance du grid : prochain projet

## compétences acquises pendant le projet 

- organisation de mes dossiers et fichiers pour un travail plus efficace, et séparation des feuilles CSS en "desktop" d'un côté et "mobile" de l'autre. 
- apprentissage des bases de la structuration HTML, éviter le plus possible les divs quand elles pouvaient être remplacées par autre chose.
- premières flexboxes

## Axes d'amélioration pour les projets suivants

- supprimer complètement les duplicates de section desktop/mobile en réfléchissant et structurant mes boites à l'avance
- utiliser au moins une grid CSS (avec une flex dedans)
- appliquer les unités rem, les clamps et si possible, les variables. 
- arriver à intégrer une version light du template que j'avais échoué à reproduire
- intégrer les premières animations, filtres, etc. quitte à charger le prochain projet, pour entraînement

## et après ? 

Ce projet a été fini en 28 jours, il m'a permis de noter quelles étaient mes plus grandes faiblesses (la non-maîtrise des boites, les boites c'est la vie), et de me fixer des challenges pour le prochain projet, pour le meilleur ou pour le pire.
